# GestiLab Squadre — app Android (installazione diretta)

Questo repository contiene SOLO i file di installazione (APK) dell'app **GestiLab Squadre** per Android, per i telefoni che non possono usare il Play Store.

## Come installare

1. Apri la pagina **Releases** e scarica l'ultimo file `.apk`.
2. Apri il file scaricato sul telefono e conferma l'installazione. Se Android chiede di consentire le installazioni da questa origine, accetta.
3. Avvia l'app e accedi con le tue credenziali.

## Attenzione

- Se avevi installato l'app dal **Play Store** (test chiuso), **disinstallala prima**: la firma è diversa e Android non aggiorna sopra.
- Le funzioni dell'app arrivano dal server: **non serve reinstallare l'APK** a ogni aggiornamento. Un nuovo APK serve solo quando cambia la parte nativa (notifiche, icona, permessi).
